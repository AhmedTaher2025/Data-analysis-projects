# Data Analysis Projects

This repository contains multiple data analysis projects organized into structured folders. Each folder includes datasets, documentation, and supporting files for specific case studies.

---

## Repository Structure

- **Cars_Analysis/**
  - `cars.csv` — Dataset for car analysis
  - `Cars_Project_Presentation.pptx` — Project presentation slides

- **Superstore_Analysis/**
  - `File 1.xls` — Superstore dataset
  - `Superstore_Sales_Analysis_Documentation.pdf` — Documentation and analysis report

- **Central_Superstore_DataWarehouse/**
  - `Central_Superstore.sql` — SQL scripts for data warehouse
  - `Sales_Data_Warehouse_SQL_Documentation.pdf` — Data warehouse documentation
  - `star schema model.mwb` — MySQL Workbench star schema model

- **Docs/**
  - General notes and supporting documentation

- **README.md**
  - Overview of repository and folder structure

---

## Purpose

The goal of this repository is to:
- Practice data analysis and visualization
- Build structured projects with clear documentation
- Apply concepts in SQL, Excel, and BI tools
- Showcase portfolio work in a professional format

---

## How to Use

1. Navigate to the relevant project folder.
2. Review the dataset (`.csv`, `.xls`, `.sql`) and documentation (`.pdf`, `.pptx`).
3. Use the provided files to replicate analysis or extend the project.
